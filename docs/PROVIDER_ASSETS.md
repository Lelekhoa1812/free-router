# Provider logo assets

FreeRouter bundles small local copies of provider marks so the dashboard does not depend on third-party image hosts at runtime. Marks are decorative; the adjacent provider name remains the accessible label.

| Provider | Local file | Official source |
|---|---|---|
| ZenMux | `public/brand/providers/zenmux.svg` | [ZenMux About Us](https://zenmux.ai/aboutus), Brand Asset (`big-logo.svg` hosted by ZenMux's image CDN) |
| OrcaRouter | `public/brand/providers/orcarouter.png` | [OrcaRouter site icon](https://www.orcarouter.ai/apple-touch-icon.png), linked from the official site |

Both assets were fetched from the provider-owned website/CDN on 4 November 2026. Keep the upstream attribution when replacing or resizing an asset, and do not use third-party logo aggregators as a source of truth.
